# Hospital 3D Infection Map Builder

用於在本機離線/安全資料夾中，生成專為感染管制（IPC）與訪客導覽設計的 WebGL (Three.js) 雙模空間監測系統。

## 一、 核心資安準則（Zero-PHI & Sanitization）

1. **零病患隱私洩漏（Zero-PHI）**：
   - 前端專案、程式碼與 JSON 資料檔內**嚴禁出現真實病歷號、身分證字號與姓名**。
   - 個案一律使用「確定性雜湊碼（如 HMAC Salted Hash）」或「虛擬代碼（如 CASE-2026-01）」。
   - 真實病患身分與代碼之對照，嚴格保存在本機線下加密的 Excel 對照表（Code Book），絕不上傳或打包進前端目錄。
2. **圖資脫敏處理**：
   - 僅使用公開逃生避難圖或簡化向量外框；移除所有機房、醫氣閥箱、CCTV 與門禁等機敏基礎設施標記。
3. **純前端離線架構**：
   - 採靜態 HTML/CSS/JS + Three.js，依賴套件可全置於本地 `libs/` 目錄，在無外網（Air-gapped）環境下亦能 100% 獨立運行。

## 二、 專案目錄結構規範

請於本機建立以下檔案結構：

```text
smart-ipc-3d/
├── index.html            # 主頁面（視角切換開關、時間滑桿、HUD 資訊抽屜）
├── css/
│   └── style.css         # 醫療儀表板深色/淺色風格樣式
├── js/
│   ├── app.js            # Three.js 場景、相機 Tween 動畫、三層式下鑽管理器
│   ├── timeline.js       # 時間軸滑桿引擎、群聚判定邏輯與轉床拋物線
│   └── data-store.js     # 資料載入與狀態過濾器
├── data/
│   ├── ward_layout.json  # 空間座標底冊（樓層高度 Y、病房邊界、床位 X/Z 座標）
│   └── movements.json    # 去識別化個案動態日誌（轉床區間、檢驗陽性日、菌株）
└── docs/
    └── CODEBOOK_TEMPLATE.xlsx # (僅限線下保存) 真實病歷號對應虛擬代號之對照表
三、 三層漸進式空間下鑽（Multi-Level Drill-Down）
前端必須支援以下三層相機與互動狀態轉換：

[Level 1: 3D 全棟巨觀] ──(點擊樓層)──> [Level 2: 單樓層 3D/2D 切換] ──(點擊病室/床位)──> [Level 3: 微觀下鑽抽屜]
Level 1：3D 大樓巨觀（Building Macro）：

堆疊渲染多樓層透明方塊，外緣根據各樓層當日感染數亮起警示 Badge（如 7F: CRAB +3）。

點擊特定樓層，鏡頭平滑過渡（Tween Camera）至該樓層。

Level 2：單一病房單位（Ward 3D/2D 雙模）：

3D 模式：1.2m 矮牆立體透視、半透明走廊與立體床位。

2D 模式：一鍵切換正上方俯瞰（Orthographic View），呈現如護理白板般的平面格局圖。

提供麵包屑導航（東址 > 7 樓 > 7D 病房）與「返回全棟」按鈕。

Level 3：病室與病床微觀下鑽（Room & Bed Detail）：

點擊病室時，鏡頭對焦至該房間；點選床位（Raycaster）在側邊彈出 HUD 卡片：

顯示：床號、病房型態（單人/負壓/雙人）、個案虛擬代碼（Case Code）、檢出菌株、感染部位、隔離防護類別、導管留置天數。

備註註腳：「真實病患身分請線下查閱實體 Code Book」。

四、 時間軸連動與傳播動線重播
時間軸控制器：

畫面底層配備日期拉桿，支援按日拖動、播放與暫停。

床位動態著色：

空床：半透明灰藍色；一般佔床：低彩度灰白色。

檢出抗藥性菌株：CRAB 亮紫色、CRE 亮橘色、VRE 藍色、MRSA 綠色。

同室群聚呼吸光暈（Cluster Alert）：

當同一病房在選定日期出現 2 例以上同菌株感染時，病房邊界自動觸發紅色脈衝呼吸光暈。

轉床移動拋物線（Transfer Arc）：

當病人自 A 床轉至 B 床，在兩床之間繪製 3D 二次貝茲發光曲線，動態指示接觸傳播軌跡。

五、 訪客導覽模式支援（Visitor View）
右上角提供【感管管理員 / 訪客導覽】切換器。

訪客模式：隱藏所有感染數據、時間軸與菌種圖例；凸顯護理站、電梯、安全梯、公廁位置與房號標籤，並支援「起點到終點」路徑導引線。
