# 臺大醫院智慧監測系統

本專案為結合 **Three.js 3D 空間可視化** 與 **2D 病房平面圖繪製** 的智慧醫療院區與感管監測平台。

---

## 🌟 核心功能

1. **完整院區 3D 數位孿生導覽**
   - **東址大樓**：經典四連棟暖黃病房塔、挑高中庭、三連三角山牆迎賓車道大廳與直升機停機坪。
   - **西址院區**：歷史紅磚文藝復興建築群、古典拱廊、中央大廳與東西翼病房。
   - **兒童醫療大樓（兒醫大樓）**：鮮黃 A 字斜柱、深藍玻璃帷幕、粉紅基座與空中花園。
   - **健康大樓**：臨中山南路首排，下層經典紅磚飾白色橫向百葉條紋、上層暖砂岩米色花崗石材、東北側立體內凹藍色帷幕採光槽，以及 2F～3F 直通兒醫大樓之高架空橋。
   - **景福地下通道**：穿越中山南路地底、串聯東址與西址之地下聯絡通道。
   - **周邊景觀與交通**：中山南路綠意路樹、常德街景觀、景福門、草坪綠帶、道路標線與動態車流。

2. **樓層切換與分層剖切（3D / 2D 平面）**
   - 支援各棟建築自 1F 至頂樓的全棟/單層剖切檢視。
   - 快速切換 3D 透視模型與高精度 2D 病房平面圖。
   - 房號、床號（東西向床位擺設）清晰標註，提供純淨免標籤視覺。

3. **感管動線與時間軸監測**
   - 個案屬性顏色標示：支援以床框顏色與點標辨識單一或多重複合屬性。
   - 時間軸動態回放與監測資料整合。

## 🚀 快速啟動

專案採用原生前端技術打造（HTML5 / JavaScript ES6 / Three.js），無需複雜編譯流程：

### 方法一：使用 VS Code Live Server 或本機 HTTP 伺服器（推薦）
```bash
# 使用 Python 啟動本機伺服器
python -m http.server 8080
```
開啟瀏覽器前往：`http://localhost:8080/index.html`

### 方法二：直接開啟
直接以支援 WebGL 的現代瀏覽器（Chrome, Edge, Firefox, Safari）雙擊開啟 `index.html`。
