# 院區 3D 導覽｜GitHub 上傳包

這是 NTUH_3D 的靜態網站發布工作副本，已設定 GitHub 遠端。2026-11-02 已同步目前開發主程式，並依資產內容更新快取版本。此包保留目前院區／病房功能；沒有包含製作過程截圖、舊版備份、除錯檔、校核報告、試算表或舊版 smart-ipc-3d 專案。

## 本機預覽

請在此資料夾開啟 PowerShell，執行：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

瀏覽 `http://127.0.0.1:8765/`。建議使用本機伺服器預覽，不要直接雙擊 `index.html`。

## GitHub Pages

將本資料夾中的檔案與子資料夾放在儲存庫根目錄。建立儲存庫後，把本資料夾內容上傳，再到 Settings → Pages 設定發布來源。

## 內容

- `index.html`、`css/`、`js/`、`libs/`：應用程式本體。
- `floorplans/`：程式載入的院區平面圖圖片。
- `scratch/`：僅保留程式實際載入的 12 張校核底圖。
- `素材/`：介面 PDF 連結使用的 33 份原始 PDF；未納入來源試算表及床號清單。

上傳前請再確認你有權將上述圖面與資料放到目標 GitHub 儲存庫。儲存庫： https://github.com/heigilin/NTUH_3D 。歷史截圖、舊備份與檢查輸出不納入發布內容。
## 階層式主選單

- 直接點選建築進入樓層及病房；header 保留建築／病室快速搜尋。
- 監測資料：目前為動線示範；預留隔離醫囑、HAI（BSI／UTI／SSI／CDI／RTI／Others）、微生物（細菌／病毒）三類主題。
- 檢視與工具：3D 鳥瞰、全棟透視、調向面板、畫布與重設。

採單一主題檢視，預留疊加模式。尚未串接的臨床主題明確標示待串接且不可選，不會產生實際監測篩選。

## 隔離醫囑核對預留

三類資料仍為獨立主題，另以狀態註記核對 MDRO／院內設定的特殊微生物個案是否有有效隔離醫囑。狀態分為有效醫囑、未查得有效醫囑、資料待確認；未串接或資料不完整時不能當成未開醫囑。比對以病人及同次住院、臨床參照時間進行，不能只用床號。介面目前待串接，未提供臨床判定。資料規劃見 docs/monitoring-linkage.json。
